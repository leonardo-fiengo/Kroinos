Place the stylized bottle images in this folder as transparent PNG files.
Use the exact lowercase filenames below:

- `intervista-alterata-fabio-rizzari.png`
- `grandi-langhe-sergio-germano.png`
- `indicazioni-geografiche-protette-giappone.png`
- `mille-modi-per-dire-sake.png`
- `i-premium-sake.png`
- `max-d-addario-stilista-olio.png`
- `cambiamenti-climatici-scenari-futuri.png`
- `la-questione-nolo.png`
- `sake-processo-produttivo.png`

Recommended format:

- Transparent background
- Portrait canvas
- Bottle centered and fully visible
- Consistent canvas ratio for every asset
- At least 1200 px tall
